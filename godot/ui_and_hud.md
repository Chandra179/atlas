# UI and HUD

## Layout and Controls

- [Fundamental] `Control` nodes, anchors, offsets, and size flags
- [Fundamental] Containers: `HBoxContainer`, `VBoxContainer`, and `GridContainer`
- [Fundamental] `Label`, `Button`, and `TextureProgressBar` for health and stamina
- [Fundamental] `CanvasLayer` so the HUD stays fixed on screen

## Polish

- [Improvement] Themes and `StyleBox` for a consistent look
- [Improvement] Focus navigation for gamepad menus
- [Improvement] Responsive layout for different screen sizes
- [Advanced] Animated UI with tweens (see [timers_and_tweens.md](timers_and_tweens.md))
- [Advanced] Custom `Control` drawing with `_draw()`
