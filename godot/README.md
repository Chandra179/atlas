# Godot Learning Notes

Roadmap for learning Godot and building a third-person fighting game with a shared character system.

## Tags

Each item in the topic files is tagged by priority:

- **[Fundamental]** - core Godot knowledge needed before building the game
- **[Improvement]** - needed for a polished game, learn after the prototype works
- **[Advanced]** - optional or later-stage depth

## Files

- [fundamentals.md](fundamentals.md) - scene tree, nodes, transforms, and visual basics
- [gdscript_basics.md](gdscript_basics.md) - language basics, node lifecycle, signals, and typing
- [math_3d_coordinates.md](math_3d_coordinates.md) - vectors, transforms, directions, and interpolation
- [resources_and_data.md](resources_and_data.md) - resources, exported data, and scene instancing
- [physics_and_collision.md](physics_and_collision.md) - physics bodies, layers, areas, raycasts, and hitboxes
- [player_controller.md](player_controller.md) - input handling, movement, gravity, and jumping
- [camera_and_targeting.md](camera_and_targeting.md) - camera rigs, framing, and target selection
- [character_animation.md](character_animation.md) - rigs, blending, root motion, and IK
- [combat_system.md](combat_system.md) - combat states, timing, and combat-animation sync
- [environment_and_graphics.md](environment_and_graphics.md) - lighting, environment, materials, and art direction
- [visual_effects.md](visual_effects.md) - particles, hit feedback, and shader effects
- [ui_and_hud.md](ui_and_hud.md) - Control nodes, containers, health bars, and menus
- [timers_and_tweens.md](timers_and_tweens.md) - timers, tweens, and timed gameplay events
- [saving_and_settings.md](saving_and_settings.md) - user data, settings files, and save games
- [audio.md](audio.md) - audio players, buses, and combat sound feedback
- [navigation_and_ai.md](navigation_and_ai.md) - navigation meshes, AI opponents, and reaction timing
- [testing_and_version_control.md](testing_and_version_control.md) - debugging, test scenarios, and Git
- [optimization_and_export.md](optimization_and_export.md) - profiling, performance, and export
- [character.md](character.md) - base character and character-specific system design
- [assets_resources.md](assets_resources.md) - trusted asset sources and license checks

## Suggested Order

1. Fundamentals and GDScript basics
2. Math and 3D coordinates
3. Resources and data
4. Prototyping with greybox shapes
5. Player controller, input, and physics
6. Camera and targeting
7. Timers, tweens, and UI basics
8. Character models and animation
9. Combat system and combat feedback
10. Environment, graphics, and visual effects
11. Audio, saving, and settings
12. Navigation and AI
13. Testing, optimization, and export
